STEPSTYLE DEMO — STATIC WEBSITE
================================
This is a customer-facing demo for a local slipper shop.

Deploy on Render:
1. Create a GitHub repository.
2. Upload index.html.
3. In Render choose New > Static Site.
4. Connect the repository.
5. Build Command: leave empty.
6. Publish Directory: .
7. Deploy.

The demo uses placeholder products, prices, phone number, email and location.
Replace them with the customer's real information before production.

Important:
- The checkout is a DEMO and does not process real payments.
- The map area is intentionally a placeholder until the shop address is known.
- Amazon/Flipkart listing is a separate seller-account/catalogue process.
